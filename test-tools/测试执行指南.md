## 二、JMeter 性能测试

### 1. 安装 JMeter
- 下载地址：https://jmeter.apache.org/download_jmeter.cgi
- 下载 apache-jmeter-5.6.2.zip
- 解压到任意目录
- 运行 `bin/jmeter.bat`（Windows）

### 2. 准备工作

**重要：先用 Postman 执行 `1.1 用户注册` 确保测试用户 `testuser_postman` 已注册**

如果你的登录接口有限流（10次/分钟），需要临时关闭限流或调大阈值，否则100并发登录会被限流。
可以在后端代码中临时注释限流逻辑，测试完再恢复。

### 3. 打开测试计划
1. 启动 JMeter
2. 文件 → 打开 → 选择 `test-tools/jmeter/vaccine-system-test-plan.jmx`
3. 你会看到左侧树形结构：
   - setUp - 获取测试Token
   - 线程组1-用户登录（100线程×50循环）
   - 线程组2-疫苗列表查询
   - 线程组3-疫苗详情查询
   - 线程组4-创建预约
   - 线程组5-预约列表查询
   - 聚合报告
   - 查看结果树
   - 汇总报告

### 4. 调整参数（如需要）

如果你的电脑配置较低，可以先降低并发数测试：
- 点击每个线程组，将 **线程数** 从100改为20或50
- 将 **循环次数** 从50改为10
- 将 **持续时间** 从300改为60

确认数据库中疫苗ID=1存在（线程组3和4用到了）。如果不存在，修改对应请求中的ID。

### 5. 执行测试

#### 第一步：先单独测试Token获取
1. 右键 `setUp - 获取测试Token` → 启用
2. 禁用其他所有线程组（右键 → 禁用）
3. 点击绿色 ▶ 启动按钮
4. 查看 `查看结果树`，确认登录成功并获取到Token
5. 截图：查看结果树中登录请求的响应数据

#### 第二步：执行完整压力测试
1. 启用所有线程组
2. 点击绿色 ▶ 启动按钮
3. 等待测试完成（约5分钟）
4. 右上角会显示运行中的线程数和已完成的请求数

#### 第三步：查看和截图结果

**聚合报告截图（最重要）：**
1. 点击左侧 `聚合报告 (Aggregate Report)`
2. 截图整个表格，包含以下列：
   - Label（接口名称）
   - # Samples（样本数）

   - Median（中位数）

   - Max（最大值）
   - Error %（错误率）

**查看结果树截图：**

2. 选择一个成功的请求（绿色图标）
3. 截图：请求详情和响应数据

**汇总报告截图：**

## 三、注意事项

1. **执行顺序**：先跑Postman（注册测试用户），再跑JMeter（需要已注册的用户）
2. **限流问题**：JMeter压测登录接口时，如果有限流会导致大量429错误。建议优先压测不需要频繁登录的接口（疫苗列表、疫苗详情），不要为了压测而删除生产限流逻辑。
3. **数据清理**：压测会产生大量预约数据，测试完后可以清理：
   ```sql
   DELETE FROM appointment WHERE remark = 'JMeter压力测试';
   DELETE FROM user WHERE username = 'testuser_postman';
   ```
4. **截图技巧**：
   - Postman截图用 Alt+PrintScreen 截当前窗口
   - JMeter聚合报告可以右键表格 → Save Table Data 导出CSV
   - 截图时确保数据完整可见，必要时调整窗口大小
5. **如果Token过期**：JMeter的setUp线程组会在测试开始时自动获取Token，如果测试时间超过24小时需要重新获取
